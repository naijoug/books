# 生命周期标注描述引用关系

**问题**：生命周期是不是让变量活得更久？

**要点**：

- 生命周期不改变值的存活时间。
- 它只告诉编译器多个引用之间的关系。
- 大多数时候编译器可以自动推断。

**示例**：

```rust
fn longest<'a>(left: &'a str, right: &'a str) -> &'a str {
    if left.len() >= right.len() {
        left
    } else {
        right
    }
}
```

**坑**：生命周期标注不是“修复悬垂引用”的魔法。如果返回引用指向局部变量，标注也救不了。

**检查**：返回引用时，能否明确说出它来自哪个输入？
