# 启动层只负责初始化，不应该长期参与运行

**问题**：`BOOTSTRAP`、初始化脚本或新手引导应该保留在长期运行上下文里吗？

**要点**：

- 启动层适合第一次询问身份、补齐配置、创建目录。
- 初始化完成后，运行时应读取稳定文件，而不是反复执行启动逻辑。
- 如果保留历史模板，要标注它是素材，不是当前状态。

**示例**：

```text
第一次运行：BOOTSTRAP.md -> 生成 IDENTITY.md 和 USER.md
后续运行：读取 IDENTITY.md、USER.md、TOOLS.md、HEARTBEAT.md
```

**坑**：长期保留未标注的启动模板，会让后续维护者分不清“待初始化”和“已初始化”。

**检查**：删除启动模板后，助手是否仍能正常说明身份、读取偏好并执行任务？如果能，启动层已经完成使命。
