# 交接必须写下一步动作，不要只写状态

**问题**：一个 Agent 结束任务后，如何让下一个 Agent 不用重新猜上下文，能直接继续推进？

**要点**：

- 交接不是总结全文，而是把“下一次该做什么”交给未来执行者。
- 最小交接包含：当前状态、已验证证据、未完成原因、下一步动作、禁止事项。
- 下一步动作要可执行、可定位、可验证；避免写“继续优化”“继续完善”这类空泛表述。

**示例**：

```text
后续接力：下一次先检查 `chapters/ai-agent/README.md` 的卡片数是否等于实际文件数；
若一致，再新增一张 `handoff-must-name-next-action.md` 风格的正式卡片并同步总索引；
不要在没有真实反馈前修改样品包正文。

验证证据：本轮已运行计数脚本，AI Agent 目录为 10 张，全书合计 79 张。
```

**坑**：

- 只写“已完成很多工作”，下一个 Agent 仍然要重新阅读全部历史。
- 只写目标，不写文件路径或验证方式，下一轮容易选错边界。
- 把愿望当计划，例如“后续考虑商业化”，但没有第一步动作。

**检查**：把交接单独拿出来读，是否能回答三个问题：从哪个文件开始、做哪一件小事、用什么方式确认做完？如果不能，就还不是有效交接。
