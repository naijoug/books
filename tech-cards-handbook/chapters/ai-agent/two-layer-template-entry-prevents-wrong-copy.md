# 模板入口先分两层，不要让 Agent 复制错输入

## 问题

同一条工作流沉淀出样本包、一页纸、决策表、命令梯和交接模板后，Agent 很容易在还没判断风险时随机复制最长模板；结果是小任务被大模板拖慢，或需要完整 preflight 时只用了轻量 checklist。

## 要点

- **第一层是 30 秒入口**：用“当前最大风险”把人或 Agent 直接分到一个最可能的模板，例如 proof checker、全量 proof 基线、preflight wrapper、下一条安全命令梯或未验证项交接。
- **第二层是 2 分钟展开判断**：当第一层无法决定时，再用决策表比较触发条件、输入证据、输出物和停止语义。
- **入口要指向动作，不只是目录**：每个分支都要说“复制哪份输入”和“第一条验证命令/检查是什么”。
- **长样本包只做补全**：长样本包适合完整接力和字段补齐，不应该替代入口判断。

## 示例

```text
当前最大风险 -> 入口
- 不知道本次文档小改是否破坏链接 -> 复制 proof checker 一页纸，先跑窄范围 markdown proof
- 全量 proof 从未跑绿过 -> 复制 full baseline 一页纸，先记录红/绿基线和失败分类
- 命令已经稳定但散在 notebook 里 -> 复制 preflight wrapper 一页纸，先定义默认/快速模式
- 只有“再跑测试”的泛泛清单 -> 复制 next safe command ladder，先写 pass/fail 语义
- 结论里还有未覆盖边界 -> 复制 unverified handoff，先拆已验证事实和未验证项
```

## 坑

- 只维护一个“大而全”样本包，会让短节拍任务每次都重新理解全套背景。
- 只维护很多小模板但没有入口，会让 Agent 继续靠猜测选择模板。
- 入口只写“看上方/下方”，没有稳定文件名或锚点，后续重排后容易失效。
- 把第二层决策表写成教程长文，会让它失去“2 分钟判断”的作用。

## 检查

- 新增或重排模板时，能否在 30 秒内回答“当前最大风险是什么，复制哪份输入”？
- 第一层入口是否覆盖最常见的 4–6 个风险，而不是列出所有文件？
- 第二层决策表是否包含触发条件、输入证据、输出物和停止语义？
- 最终报告或 notebook 是否记录本轮选择了哪一层入口，以及为什么没有使用其它模板？
