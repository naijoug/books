# Swift 字符串插值比拼接更清晰

**问题**：如何把变量放进字符串？

**要点**：

- 使用 `\(value)` 做字符串插值。
- 多行文本用三引号。
- 插值比多个 `+` 更容易读，也更不容易漏空格。

**示例**：

```swift
let name = "Ada"
let age = 30
let message = "Hello, \(name)! You are \(age) years old."

let text = """
Line 1
Line 2
"""
```

**坑**：大量业务文案不要散落在代码里，真实应用应接入本地化和资源管理。

**检查**：字符串是否需要本地化？需要就不要硬编码在组件内部。
