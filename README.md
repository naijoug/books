## 推荐工作流

1. 先在对应书籍的 `README.md` 确认定位、目录和下一步。
2. 新章节写入 `chapters/`，草稿写入每本书目录下的 `.drafts/`；只有可复用、已脱敏的支撑材料才放入 `resources/`。
3. 每次新增章节后同步更新该书 `README.md` 的进度表。
4. 重要事实、工具版本、数据结论需要在发布前做一次事实核验。
5. 完稿前统一做结构审查、术语统一、交叉引用和格式清理。
