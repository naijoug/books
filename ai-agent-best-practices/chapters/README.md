## 阅读建议

1. 新手按章节顺序阅读，先建立 Agent 的基本概念和设计原则。
2. 已有开发经验的读者可以从第 4-7 章进入架构和工具集成。
3. 准备上线生产系统时，重点阅读第 8-10 章，并按“测试集与评估报告字段 → 发布监控与灰度报告 → 安全门禁 → 熔断恢复”的顺序落地。

## 生产上线阅读路径

- 第 7 章：确认工具注册、工具描述、执行沙箱、权限边界、工具路由和供安全回归/发布门禁使用的工具安全元数据。
- 第 8 章：把关键任务写成 Golden Tasks，覆盖成功路径、失败路径、权限测试、敏感字段扫描和可进入发布门禁的安全回归集；评估报告需要沉淀 `release_id`、`safe_trace_links`、`audit_event_ids` 等共享字段。
- 第 9 章：建立部署、监控、告警、灰度、回滚和成本止损机制，并把第 8 章的评估报告、失败样本 ID、脱敏执行 trace 与审计事件接入同一条发布流水线。
- 第 10 章：补齐 Prompt 注入防御、数据脱敏、人工审批、脱敏执行 trace、审计日志、事故熔断 runbook 与发布前安全检查清单；安全门禁报告应直接引用第 8 章产出的评估证据。
