# 《AI 时代个人提升指南》

## 书籍信息

- **书名**:AI 时代个人提升指南
- **副标题**:从入门到精通,打造不可替代的核心竞争力
- **定位**:一本面向普通职场人、学生、创作者和程序员的 AI 时代个人成长实践指南。
- **核心主张**:AI 不是替代人的工具,而是放大人的学习、工作、创作和职业发展能力的协作者。
