# 书稿审查

适用于检查已有书稿。根据目标读者和本次范围，检查事实准确性、必要内容、结构、可读性及受时间影响的事实；局部修订无需重审整本书。

审查模式只输出问题，不修改文件，也不按问题数量自动转成全文重写。修改由用户请求或调用方的 rewrite/full 工作流决定。

每项发现写明：优先级、章节/小节位置、问题与证据、影响、建议修复。区分确定错误、待核验事实和可选风格建议。没有问题时直接说明未发现问题及检查范围，不制造评分或凑足固定数量。

检查卡片时保留“问题、要点、示例、坑、检查”；长章节按学习目标判断，不强制代码、正反案例或固定小节数。资料新旧按适用版本判断，不能只因不是最新版而要求重写。

完成标准：报告足以定位并修复问题，同时说明未执行代码、未打开来源等实际验证限制。报告默认只返回给调用方。
